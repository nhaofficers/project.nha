# User guide

1. Sign in with your assigned account.
2. Contributors select **Upload photos**, choose a project/event, add mandatory title and capture date, and submit a batch. The result lists successful, invalid, and duplicate items independently.
3. Reviewers open pending items, correct metadata, then approve or reject. Only approved photos are visible to ordinary viewers.
4. Use Archive filters for project, event, year, activity, tags, status, or keyword. Select one photo to download or several to request a temporary ZIP.
5. Presentation managers create a presentation, select a template, arrange referenced photos, edit captions, preview, and generate a temporary PPTX.
6. Administrators manage accounts, taxonomy, storage thresholds, templates, and audit records.
